# Academic portfolio website

An English, buildless personal website prepared for GitHub Pages. Open `index.html` locally to preview it. There are no dependencies or build steps.

## Personalize it

Replace every square-bracketed placeholder in `index.html` with verified information. In particular, update the name, education, public email, research interests, research experience, introduction, page title, and description. Add a CV PDF under `assets/cv.pdf`, then replace the CV status box with a link to `assets/cv.pdf` (with a `download` attribute if desired). Add a photo only if you want one. When the real content is ready, remove the temporary `noindex, nofollow` robots meta tag so search engines can index the site.

## Publish on GitHub Pages

For a user site, create a public repository named `<username>.github.io`, put `index.html` and `style.css` at its root, and enable Pages with the root of the default branch as the source. The resulting URL is `https://<username>.github.io/`. The GitHub account identified for this task is `Chujia-Y`, so its intended repository would be `Chujia-Y/Chujia-Y.github.io`.
